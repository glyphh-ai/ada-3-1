# Fast weights, dual form of gradient descent, dynamic evaluation and test-time training: prior art for "route memory with surprise nudging"

Scope note. The method under check: frozen pretrained transformer LM; store per token (key = MLP on/off route, told = next token, predicted = model's own distribution); at generation add `eta * sum_i P[i] * (onehot(told_i) - predicted_i)` to the log-probabilities, P = a similarity kernel. Claimed equivalent: one gradient step per stored token on the unembedding, `dW = sum_i (told_i - predicted_i) key_i^T`, kept in dual form.

Verification legend: **[P]** = read from the primary paper text (arXiv HTML / ar5iv) in this session. **[S]** = seen only in a search snippet or abstract. **[M]** = from my memory of the literature, NOT verified in this session (treat as a lead, check before citing).

Bottom line up front (details per question below):
- Every ingredient of step 3 is published: the last-layer gradient `(target - p) h^T` (Rae 2018 eq. 2; Gao 2023 eq. 14; MbPA 2018), the dual form `W0 x + sum_t (x_t . x) e_t` with stored error signals as values (Irie 2022, after Aizerman 1964), and the explicit observation that kNN retrieval at the output layer is that dual form with the error signal truncated to the one-hot label, the `- P` term being exactly what is missing (Gao et al. 2023, kNN-MT).
- The closest working method is MbPA (Sprechmann et al. 2018): kernel-weighted gradient steps on the softmax layer of a pretrained LM from retrieved (hidden state, next word) memories, weights adapted temporarily and discarded. One MbPA step from the unmodified weights, written out, is `logits + alpha * sum_k w_k (h_k . h) (onehot(v_k) - p_k)`, which is step 3 with kernel `w_k (h_k . h)`.
- I found NO paper that implements it the way the method does: store `(told - predicted)` itself, never touch weights, apply at the logits of a frozen pretrained LLM through a non-hidden-state kernel, ungated and unnormalised. Searches for that exact combination (three extended searches) returned nothing. So the explicit non-parametric implementation looks unpublished, but it is a short derivation away from published statements, and a reviewer would call it "one-step MbPA / dual-form output-layer dynamic evaluation with a different kernel".
- Caveat on the method's own claim: it is "exactly one gradient step on the unembedding" only when the kernel is the hidden-state dot product `h_i . h`. With a route-agreement kernel it is a functional-gradient (kernel machine) step in the feature space that kernel induces, not a step on the model's actual unembedding weights.

## Fast weights: which works apply an outer-product update to the output/softmax layer from a stored (activation, target) pair?

### Takeaway
Rae et al. 2018 (Hebbian Softmax) and Sprechmann et al. 2018 (MbPA) both write into the softmax layer from (activation, target) pairs, and MbPA does it at test time on a pretrained LM from a retrieved memory with a kernel; neither stores the error term nor keeps the update in dual form, and Hebbian Softmax writes the raw activation, not the error. The other fast-weight works act on hidden-layer weights, not the output layer.

### Cited Findings
- **Rae, Dyer, Dayan, Lillicrap 2018, "Fast Parametric Learning with Activation Memorization" (ICML 2018). [P]** Two-part update on softmax weights `theta`. Gradient part (eq. 2): `theta[i] <- theta[i] - alpha (p_i - 1) h_t` for `i = y_t`, `theta[i] <- theta[i] - alpha p_i h_t` otherwise, i.e. the standard `(onehot - p) h_t^T` output-layer step. Hebbian part (eq. 3): `theta[y_t] <- lambda_t h_t + (1 - lambda_t) theta_hat[y_t]`, with `lambda_t = max(1/c_t[y_t], gamma) * 1{c_t[y_t] < T}`. So the "Hebbian" write is the RAW activation `h_t` into the row of the told word (no error term), only for rare words, during TRAINING, and the weights ARE modified. The paper derives a kernel/cache reading: under approximations `theta_i ~ sum_j lambda (1-lambda)^(j-1) h_{I_w(j)}`, giving `p(w|h_t) ~ prod_j exp(lambda (1-lambda)^(j-1) h_t^T h_{I_w(j)})`, "a proxy for" an infinite cache model. — [ar5iv 1803.10049](https://ar5iv.labs.arxiv.org/html/1803.10049); [PMLR](https://proceedings.mlr.press/v80/rae18a.html)
  - Difference from the method: training-time, weights modified, stores activation not surprise (the Hebbian write fires regardless of whether the model already predicted the word), not a frozen pretrained LLM, key = final hidden state.
- **Sprechmann et al. 2018, "Memory-based Parameter Adaptation" (MbPA, ICLR 2018). [P]** Memory `M = {(h_i, v_i)}`: keys = embedding-network outputs, values = targets. Retrieval: K nearest neighbours, kernel `kern(h, q) = 1 / (eps + ||h - q||^2)`, `w_k ∝ kern(h_k, q)`. Local adaptation (eq. 4): `Delta_M(x, theta) = -alpha_M grad_theta [ sum_k w_k log p(v_k | h_k, theta^x, x) ] - beta (theta - theta^x)`, a fixed number of steps; "These adapted parameters are used for output computation but discarded thereafter." Language modelling: a PRE-TRAINED LSTM, MbPA adapts "the weights and biases of its output softmax layer", memory holds past LSTM outputs and observed next words at evaluation time. PTB 59.6 -> 54.3, WikiText-2 65.9 -> 56.0 (49.4 with cache; text and table disagree by 0.6). Appendix E: attention over memories `p_mem(y=j|q) = sum_i w_i delta(v_i=j) / sum_i w_i` is the solution of a kernel-weighted NLL fit of a constant; "we can think of MbPA as a generalisation of the attention mechanism". The paper notes the correction shrinks as the parametric model already fits the memories (the "only surprise pushes" property). No dual form is discussed. — [ar5iv 1802.10542](https://ar5iv.labs.arxiv.org/html/1802.10542)
  - Difference from the method: MbPA materialises temporary weights and recomputes gradients at query time (values stored are labels, the prediction `p_k` is recomputed, not stored); kernel is a distance on final hidden states; LSTM, not a frozen transformer LLM; has an L2 pull-back term. Mathematically one step without the pull-back equals step 3 with kernel `w_k (h_k . h)`.
- **Irie, Csordás, Schmidhuber 2022** credit the unnormalised-attention view of fast weights to Schmidhuber 1993 and Ba et al. 2016; the term "spotlights of attention" is taken from Schmidhuber's 1993 fast weight controllers. — [ar5iv 2202.05798](https://ar5iv.labs.arxiv.org/html/2202.05798)
- **FAAST (Bao et al., May 2026), "Forward-Only Associative Learning via Closed-Form Fast Weights for Test-Time Supervised Adaptation". [P]** Frozen encoders give `k_i`, `v_i`; fast weights by least squares `W* = K^+ V` (pseudoinverse with spectral truncation), not Hebbian, not an error-driven delta rule; stored as a primal matrix (pairs can be discarded). Classifiers: applied at the output projection, interpolated with pretrained `W0`. Language models (GPT-2 117M to 1.5B, WikiText-103; Qwen2.5 for translation): inserted in INTERMEDIATE hidden layers (key = hidden state at t, value = hidden state at t+1) with a readout `P_l` and an importance scorer that are trained once. GPT2-XL: FAAST 15.35 PPL vs kNN-LM 12.70 vs linear projection 13.60. Cites Ba 2016, Miconi 2018, Hopfield, Hinton & Plaut; does not discuss dynamic evaluation or the dual form. — [arXiv 2605.04651](https://arxiv.org/html/2605.04651v2)
  - Difference from the method: closed-form regression on targets (no `target - prediction`), primal weights, hidden layers for LMs, needs a trained readout. It is the nearest 2026 "backprop-free fast weights on a frozen LLM" paper and shares the framing, not the rule.

### Inferences
- "Outer-product update of the output layer from a stored (activation, target) pair" is published twice over (Rae 2018 training-time; MbPA 2018 test-time, pretrained LM, kernel-weighted). The method's contribution cannot be that idea as such.
- The "surprise only" property is not new either: any cross-entropy gradient on the softmax layer is `(onehot - p) h^T` and vanishes where the model was right; MbPA states the consequence in words.

### Gaps
- Schmidhuber 1992/1993, Hinton & Plaut 1987, Ba et al. 2016, Munkhdalai & Trischler 2018, Metalearned Neural Memory 2019, Miconi 2018 were NOT opened in this session. **[M]**: Ba et al. 2016 use `A(t) = lambda A(t-1) + eta h(t) h(t)^T` on hidden-to-hidden weights (Hebbian, raw activations, trained end to end); Munkhdalai & Trischler's Hebbian fast weights and MNM's learned local update rules act on memory/hidden layers with meta-learned rules; Miconi's plasticity is a learned Hebbian trace per connection; none is a frozen-LLM logit correction and none stores `target - prediction` at the vocabulary softmax. Verify before citing.

## Dual form of gradient descent: does any work build an explicit inference-time memory on a frozen LLM by storing error signals and applying them through a kernel?

### Takeaway
No. The dual form with stored error signals as attention values is published as an analysis tool (Irie 2022) and as an explanation of in-context learning and of kNN-MT (Dai 2023, Gao 2023), and Gao et al. come within one term of the method, but none of them builds the memory explicitly on a frozen LLM.

### Cited Findings
- **Irie, Csordás, Schmidhuber 2022 (ICML). [P]** Primal `W = W0 + sum_t e_t x_t^T`; dual `S(x) = W0 x + sum_t (x_t^T x) e_t` = unnormalised dot-product attention with keys = layer inputs seen in training, values = error signals `e_t = -eta_t (grad_y L)_t` (learning rate folded in). Used for analysis/visualisation; the paper calls the dual form "not a practical form for regular settings" (storage linear in the number of training patterns) and says the analysis "is not applicable to models which are already trained". LM experiments: one-layer LSTMs on WikiText-2 and a small character corpus, studying the LSTM's internal linear layer. Cites Aizerman et al. 1964 as the origin of the primal/dual perceptron forms, plus the SVM/kernel literature and Domingos 2020. — [ar5iv 2202.05798](https://ar5iv.labs.arxiv.org/html/2202.05798); [PMLR](https://proceedings.mlr.press/v162/irie22a.html)
  - Difference: requires having trained the layer by gradient descent yourself; no frozen pretrained LLM, no new memory written at inference, kernel is the plain dot product of the layer's inputs, not specific to the unembedding. The method is this dual form instantiated for one hypothetical step on the unembedding, with the dot product swapped for a route kernel.
- **Gao, Zhang, Du, Liu, Wang 2023, "Nearest Neighbor Machine Translation is Meta-Optimizer on Output Projection Layer". [P]** (venue EMNLP 2023 is **[M]**; the page read did not state it). States the dual form `F(q) = (W0 + Delta W) q`, `Delta W = sum_i e_i ⊗ q_i = E Q^T`, `F(q) = W0 q + LinearAttn(Q, E, q)`. Writes kNN-MT as attention `p_kNN = V_m softmax(K_m^T h / T)` and, with the softmax relaxed, `F_all(h) = (W_O + (lambda/T) Delta W_kNN) h`, `Delta W_kNN = E_m K_m^T - (T/2) d||W_O||^2/dW_O`, with **`E_m = V_m`** (one-hot labels). Then writes explicit output-projection fine-tuning: `Delta W_FT = (V_m - P_m) K_m^T - alpha W_O`, `P_j^m = softmax(W_O K_j^m)`. It says kNN-MT "solely utilizes the label of k-nearest-neighbors as error signals", "without considering the prediction of the NMT model, which may weaken the label signal". Weights are never modified in kNN-MT; the equivalence holds under a relaxed linear attention and is "not rigorously proven" for softmax attention. The paper does NOT propose or test a datastore of `V - P`; the `V - P` signal appears only in the parametric OPL fine-tuning baseline. — [ar5iv 2305.13034](https://ar5iv.labs.arxiv.org/html/2305.13034)
  - Difference: this is the nearest published statement of the framing. Their eq. 14 pushed through their own eq. 5-7 is exactly step 3 with kernel `K_j . h`. What they did not do: implement it non-parametrically, store `P`, use it on an LLM for language modelling, or use a non-hidden-state kernel. A fair reading: the method is "the dual form of Gao et al.'s OPL fine-tuning step, which they wrote but only ran in primal form".
- **Dai et al. 2023, "Why Can GPT Learn In-Context? Language Models Implicitly Perform Gradient Descent as Meta-Optimizers" (Findings of ACL 2023). [S]** Transformer attention has a dual form of gradient descent; "GPT first produces meta-gradients according to the demonstration examples" and applies them through attention; adds momentum to attention values. Explanatory; the "error signals" are attention values the model computes itself, not stored `target - prediction` at the logits; no external memory. — [arXiv 2212.10559](https://arxiv.org/abs/2212.10559); [ACL Anthology](https://aclanthology.org/2023.findings-acl.247)
- **von Oswald et al. 2023, "Transformers learn in-context by gradient descent". [S]** A weight construction for linear self-attention so that a forward pass equals gradient-descent steps on in-context linear regression. Constructive/explanatory, trained small transformers; no explicit memory on a frozen LLM. — [ar5iv 2212.07677](https://ar5iv.labs.arxiv.org/html/2212.07677)
- **Han et al. 2023, "Explaining Emergent In-Context Learning as Kernel Regression". [S]** ICL behaves like `y_hat = sum_i y_i K(x, x_i) / sum_i K(x, x_i)`: a NORMALISED average of labels (Nadaraya-Watson), not an additive sum of residuals. — [arXiv 2305.12766](https://arxiv.org/abs/2305.12766)

### Inferences
- The dual-form reading of step 3 is not a new insight; Irie 2022 gives the identity, Gao 2023 applies it to the output projection and names the missing `- P` term. What is unpublished (as far as found) is turning that into the mechanism itself.
- Strictly, in the dual form the kernel is forced to be `key_i . key_query` in the layer's own input space. Swapping in route agreement means the method is no longer the dual of a step on the real unembedding; it is the dual of a step on a virtual linear readout over the kernel's feature map. The claim "exactly one gradient step on the unembedding" should be worded accordingly.

### Gaps
- Aizerman, Braverman, Rozonoer 1964 and Akyürek et al. 2023 were not opened; Aizerman is cited here only via Irie 2022.
- **[M], unverified:** the method's structure, `f(x) = f0(x) + eta * sum_i kernel(x_i, x) * (loss-gradient residual at x_i)`, is the first pass of online kernel learning: Kernel LMS (Liu, Pokharel, Principe 2008: stored a-priori errors as coefficients of kernel units, Widrow-Hoff in an RKHS) and NORMA (Kivinen, Smola, Williamson 2004), and one stage of functional gradient boosting with a kernel smoother. With multiclass logistic loss the coefficient is `onehot - p`. Difference: KLMS/NORMA compute each error against the growing memory (so repeats stop pushing); the method computes errors against the frozen model only. I did not fetch these papers; the report writer should have them checked because they are the oldest and most exact ancestors of "store the error, apply by kernel, never write weights".

## Dynamic evaluation: is "non-parametric dynamic evaluation" or "retrieval of output-layer gradients" published?

### Takeaway
Dynamic evaluation as published always modifies parameters by gradient descent (all weights, a small adaptation matrix, or LoRA); the non-parametric counterpart discussed in that literature is the neural cache, which stores labels, not errors. I found no paper named or amounting to "non-parametric dynamic evaluation" that stores gradients/errors and applies them by similarity; MbPA is the nearest.

### Cited Findings
- **Krause, Kahembwe, Murray, Renals 2018, "Dynamic Evaluation of Neural Sequence Models" (ICML). [P]** SGD rule with global prior (eq. 4): `theta_i <- theta_{i-1} - eta grad L(s_i) + lambda (theta_g - theta_{i-1})`; RMS variants scale by gradient statistics from training data. Sparse dynamic evaluation (sec. 6): a zero-initialised adaptation matrix `M` on hidden units, `h'_t = h_t + M h_t`, only `M` adapted (500x500 = 250k parameters, about 0.5% of full). It adapts hidden states, NOT the output layer. On the cache: the neural cache "learns a type of non-parametric output layer on the fly at test time", "uses a non-parametric, nearest neighbours-like method", whereas dynamic evaluation uses gradient descent. Does not mention fast weights. — [ar5iv 1709.07432](https://ar5iv.labs.arxiv.org/html/1709.07432)
- **Krause et al. 2019, "Dynamic Evaluation of Transformer Language Models". [P]** Segment-level gradient updates on Transformer-XL (enwik8 0.99 -> 0.94 bpc, text8 1.08 -> 1.04, WikiText-103 18.3 -> 16.4 ppl). Weights modified; notes "the neural cache learns a non-parametric output layer" and suggests hybridising with it as future work; says gradient-adjusted weights "can be interpreted as a memory". No last-layer-only or non-parametric variant. — [ar5iv 1904.08378](https://ar5iv.labs.arxiv.org/html/1904.08378)
- **Mikolov et al. 2010** is described by Krause 2018 as the original dynamic evaluation: SGD updates at every time step with fully truncated backpropagation. — [ar5iv 1709.07432](https://ar5iv.labs.arxiv.org/html/1709.07432)
- **Rannen-Triki et al. 2024, "Revisiting Dynamic Evaluation: Online Adaptation for Large Language Models". [S]** Online fine-tuning of LLMs at test time including online LoRA; "online-adaptation turns parameters into temporally changing states and provides a form of context-length extension with memory in weights". Parametric, gradient-based. — [arXiv 2403.01518](https://arxiv.org/abs/2403.01518)
- A 2026 preprint characterises the field the same way: "Dynamic evaluation adapts a model's parameters to the test stream by gradient descent". **[S]** — [arXiv 2610.33025](https://arxiv.org/html/2610.33025)
- Other 2026 "training-free" test-time work found is a different mechanism: TF-TTCL stores natural-language rules for a frozen LLM ("semantic gradients", text level, not logits) **[S]** — [arXiv 2604.13552](https://arxiv.org/pdf/2604.13552); OLIVIA updates a light decision layer for ReAct agent actions as a contextual bandit **[S]** — [arXiv 2605.11169](https://arxiv.org/pdf/2605.11169); "Continual Residual Memory for Gradient-Free Test-Time Adaptation" is speech enhancement **[S]** — [arXiv 2611.01023](https://arxiv.org/html/2611.01023).

### Inferences
- Step 3 can be described accurately as "dynamic evaluation restricted to the unembedding, one step per stored token, each step taken from the ORIGINAL weights, held in dual form with a substituted kernel". Each clause has a precedent (last-layer: MbPA; one step per item: Hardt & Sun; dual form: Irie/Gao), the conjunction as an implemented method was not found.
- A real difference from true (sequential) dynamic evaluation: sequential SGD computes each error against the already-updated weights, so a fact told twice pushes less the second time. Storing the frozen model's `predicted` means repeated or mutually redundant stored tokens push additively (no explaining-away). That is the "never normalised" property, and it is a behavioural difference worth testing, not only a framing point.

### Gaps
- Krause's thesis ("4.6 Sparse dynamic evaluation") and any last-layer-only dynamic evaluation ablation were not located in a primary source. — thesis only seen in a listing: [era.ed.ac.uk](https://era.ed.ac.uk/bitstreams/8ee7de6d-7102-401f-9fe4-eb67a89ee7cc/download) **[S]**
- Grave et al. 2017 neural cache, Hinton 2022 forward-forward (its fast-weights remarks) were not opened. **[M]**: the cache stores (hidden state, next word) and adds `exp(theta h_t . h_i)` mass to the told word, interpolated; labels only, no error term.
- Absence claim rests on three extended searches with varied wording; an obscure workshop paper or a 2026 preprint under another name could exist.

## Test-time training on neighbours, kNN-LM as a gradient step, kernel views of fine-tuning

### Takeaway
Hardt & Sun do real gradient steps on all weights from retrieved text; the "kNN = implicit gradient step on the output layer" result exists for kNN-MT (Gao 2023), not as a kNN-LM paper, and it explicitly identifies the missing prediction term; kNN-LM-family datastores store the told token only.

### Cited Findings
- **Hardt & Sun, "Test-Time Training on Nearest Neighbors for Large Language Models" (ICLR 2024). [S]** Retrieve neighbours of the test input from an index over the Pile (text embeddings), "fine-tune the model on retrieved data at test time, using the standard training setup"; "as few as 20 neighbors, each for only one gradient iteration" helps on 20+ Pile tasks; narrows the gap between GPT-2 and a 10x larger GPT-Neo. Weights modified (all of them), backprop required, reset per query. — [arXiv 2305.18466](https://arxiv.org/abs/2305.18466); [ICLR](https://iclr.cc/virtual/2024/poster/19176)
  - Difference: full-model backprop per query, primal; key = text embedding of whole sequences; stores text, not per-token errors. Shares "one gradient step per stored neighbour" with the method.
- **Xu, Alon, Neubig 2023, "Why do Nearest Neighbor Language Models Work?" (ICML). [S]** Attributes kNN-LM gains to a different input representation for the next-token prediction, approximate kNN search, and softmax temperature; a separately trained embedding matrix replacing the datastore recovers about 55% of the gain. Not a gradient-step analysis; the datastore term is a matrix of one-hot told tokens. — [arXiv 2301.02828](https://arxiv.org/abs/2301.02828); [PMLR](https://proceedings.mlr.press/v202/xu23a.html)
- **Gao et al. 2023** (see previous section) is the paper that shows kNN retrieval at the output layer equals an implicit gradient step on the output projection, with `E = V` instead of `V - P`. — [ar5iv 2305.13034](https://ar5iv.labs.arxiv.org/html/2305.13034)
- **Xu et al. 2023, "On Retrieval Augmentation and the Limitations of Language Model Training". [S]** Rules out the softmax bottleneck: the trained LM's last layer can produce a distribution close to the kNN-augmented one; reports an "MLP hurdle". Relevant because it says a last-layer change can in principle reproduce what the datastore adds. — [ar5iv 2311.09615](https://ar5iv.labs.arxiv.org/html/2311.09615)
- **Malladi et al. 2023, "A Kernel-Based View of Language Model Fine-Tuning" (ICML). [S]** Tests whether the NTK describes fine-tuning of pretrained LMs; kernel behaviour appears when the task is posed as masked-word prediction via prompts; limited to few-shot classification with a masked LM. Analysis of full fine-tuning, not an inference-time memory. — [arXiv 2210.05643](https://arxiv.org/abs/2210.05643); [PMLR](https://proceedings.mlr.press/v202/malladi23a.html)
- **Nishida et al. 2025, "Long-Tail Crisis in Nearest Neighbor Language Models". [S]** kNN-LM does not help long-tail tokens; relates gains to datastore approximation error. Not a residual store. — [arXiv 2503.22426](https://arxiv.org/abs/2503.22426)
- A targeted search for a kNN-LM variant that stores "one-hot minus model prediction" in the datastore returned none. — nearest hits: [kNN-Prompt](https://arxiv.org/pdf/2205.13792), [Efficient kNN-LM](https://arxiv.org/pdf/2109.04212), [RETOMATON](https://arxiv.org/pdf/2201.12431), all label-valued datastores **[S]**

### Inferences
- Relative to kNN-LM, the method's substantive deltas are: (a) subtracting the stored model prediction (Gao et al. name this as the gap between kNN-MT and real fine-tuning but do not build it), (b) adding in log space without a mixture weight or normalisation, (c) the key/kernel. (a) and (b) together are exactly what moves kNN-LM to "a last-layer gradient step", and that sentence is, in substance, already in Gao et al.
- Relative to Hardt & Sun, the method is the last-layer, closed-form, no-backprop special case, which MbPA already occupies in primal form.

### Gaps
- Bottou & Vapnik 1992 local learning not opened. **[M]**: train a local model on the k nearest training points per test point; the conceptual ancestor Hardt & Sun cite.
- kNN-MT/kNN-LM papers that keep only entries the base model gets wrong (datastore pruning by model correctness, a gate-like relative of "only surprise pushes") were not searched to a conclusion. **[M]**: such pruning work exists for kNN-MT (e.g. Zhu et al. 2023, "What Knowledge Is Needed? Towards Explainable Memory for kNN-MT Domain Adaptation"); unverified here.
- Model-editing methods that add a closed-form rank-one term from a residual, or keep edits in a side codebook without touching weights (ROME/MEMIT, GRACE) are adjacent and were not checked in this session **[M]**; they act on mid-layer MLP values, not the logits.

## Titans and follow-ups: how does Titans' "surprise" differ?

### Takeaway
Titans' surprise is the gradient of an internal key-value reconstruction loss of a learned memory MLP whose weights are rewritten at test time inside an architecture trained from scratch; it is not next-token error at the logits and is not applied to a frozen pretrained LLM. The shared word "surprise" and "memorise at test time" are the overlap; the mechanism differs on every axis the brief lists.

### Cited Findings
- **Behrouz, Zhong, Mirrokni, "Titans: Learning to Memorize at Test Time" (arXiv Jan 2025; NeurIPS 2025 poster). [P]** Loss (eq. 12): `l(M_{t-1}; x_t) = || M_{t-1}(k_t) - v_t ||_2^2`, with `k_t = x_t W_K`, `v_t = x_t W_V` (learned projections of the same input token). Update (eq. 13-14): `M_t = (1 - alpha_t) M_{t-1} + S_t`, `S_t = eta_t S_{t-1} - theta_t grad l(M_{t-1}; x_t)` (past surprise with data-dependent decay `eta_t`, momentary surprise scaled by `theta_t`, forgetting gate `alpha_t`). The memory is an MLP (`L_M >= 1` layers) whose weights are updated at test time in an inner loop; `W_K`, `W_V`, the gates and the rest of the model are trained in an outer loop (models of 170M to 760M parameters trained with AdamW). — [arXiv 2501.00663](https://arxiv.org/html/2501.00663v1); [NeurIPS 2025](https://neurips.cc/virtual/2025/poster/119639)
  - Stored: nothing explicit, the memory is weights. Kernel/key: learned projection, read by a forward pass of the MLP. Error term applied: yes, but the error of the memory's own reconstruction `M(k) - v` in hidden space, not `told - predicted` over the vocabulary. Applied at logits: no (memory output feeds the model as context/layer). Weights modified: yes (memory module). Frozen pretrained LLM: no.
- **MIRAS** (Google Research blog, Dec 2025): a framework describing sequence models by four design choices incl. memory architecture, and treating forgetting as regularisation. **[S]** — [Google Research blog](https://research.google/blog/titans-miras-helping-ai-have-long-term-memory/)
- **ATLAS**: described in a secondary blog as updating the memory with an internal optimiser using gradients from current and past context. **[S, secondary source only]** — [blog](https://saraameli.github.io/Personal-Site/blog_MemTransformer.html)

### Inferences
- If the write-up uses the word "surprise", a reader will think of Titans; the honest one-line contrast is: Titans = learned memory network, squared-error gradient in hidden space, weights rewritten, momentum and forgetting, architecture trained end to end; this method = stored softmax residual at the vocabulary, frozen model, no weights written, no momentum, no forgetting.
- Titans' momentum (carrying surprise to following tokens) is loosely analogous to the method's carrying the kernel along the stored sequence, but one propagates a write signal and the other a read similarity.

### Gaps
- ATLAS, MIRAS and Nested Learning primary papers were not opened; nothing found applying a Titans-style memory to a frozen pretrained LLM, but that was one search.

## 2023-2026 training-free / closed-form adaptation of LLM output layers or logit correction from stored prediction errors

### Takeaway
Nothing found that stores next-token prediction errors of a frozen LLM and adds them to the logits by similarity. The nearest 2026 work (FAAST) is closed-form and forward-only on frozen LLMs but regresses hidden states on targets in mid layers, with no error term.

### Cited Findings
- FAAST (May 2026): see first section. Closed-form least squares fast weights, primal, mid-layer for LMs, loses to kNN-LM on GPT2-XL WikiText-103 (15.35 vs 12.70 PPL) unless its readout is trained on the target corpus (13.23). — [arXiv 2605.04651](https://arxiv.org/html/2605.04651v2)
- Extended searches on "training-free test-time adaptation LLM logits stored prediction errors residual memory kernel", "dynamic evaluation without backpropagation / non-parametric / kernel last-layer frozen LLM logits", and "datastore of error signals (label minus predicted probability) applied to logits via kernel, dual form, output projection" returned no matching method; hits were label-valued kNN methods, text-rule memories, vision-language TTA and agent bandits. — e.g. [TF-TTCL 2604.13552](https://arxiv.org/pdf/2604.13552), [ACTOR 2611.09084](https://arxiv.org/html/2611.09084), [Dual-kNN 2503.04869](https://arxiv.org/html/2503.04869), [plastic-llm repo](https://github.com/skoll43/plastic-llm) (unreviewed, not opened)

### Inferences
- Novelty that survives this search, stated narrowly: (1) the key/kernel (binary MLP routes, carried along the stored sequence), (2) materialising the residual `told - predicted` as the stored value and applying it non-parametrically at the logits of a frozen pretrained transformer LM, (3) doing so ungated and unnormalised. Item (2) is an implementation of an identity others have written (Irie 2022; Gao 2023 eq. 5-7 + eq. 14) and of a method others ran in primal form (MbPA 2018), so it should be claimed as "to our knowledge not previously implemented/evaluated", not as a new principle.
- The safest related-work sentence: "Our nudge is the dual form (Aizerman 1964; Irie et al. 2022) of a single output-layer gradient step per memory, i.e. one-step memory-based parameter adaptation (Sprechmann et al. 2018) with the hidden-state kernel replaced by route agreement; Gao et al. 2023 showed kNN retrieval is the same update with the prediction term dropped."
- Baselines a reviewer will demand: kNN-LM with the same keys (isolates the `- predicted` term and log-space addition), MbPA / last-layer SGD with hidden-state keys (isolates the kernel), and true sequential last-layer dynamic evaluation (isolates "errors against frozen model" vs "errors against updated model").
