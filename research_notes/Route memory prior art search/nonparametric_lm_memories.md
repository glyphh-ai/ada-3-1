# Non-parametric / retrieval-based LM memories vs. "route memory with surprise nudging"

Method under check (shorthand used below): **KEY** = binary on/off pattern of every MLP unit in every block per token; **CARRY** = `P_t[n] = sim_t[n]^scale * (1 + P_(t-1)[n-1])`, no gate/threshold/reset; **NUDGE** = `log p_model + eta * sum_n P[n] * (told_n - predicted_n)`, added to scores, never normalised into a mixture; frozen weights, no training.

Verification legend: **[read]** = method section read in this session (ar5iv full text); **[abstract]** = only the abstract was read, details beyond the abstract come from my background knowledge and are marked as such; **[search only]** = seen only in search results.

Overall verdict in one paragraph: no single surveyed work matches the method, and two of its three components (binary all-MLP-gate keys; an ungated carried soft-alignment score) were not found anywhere in this literature. The third component (the value `told - predicted` added to the logits, "one output-layer gradient step kept in dual form") **is published as mathematics and as analysis**: Irie et al. 2022 (dual form of a GD-trained linear layer = attention over stored inputs with error-signal values), Clark et al. 2022 (fast weight layers = linear attention with gradient values), and most pointedly Gao et al. 2023, who derive output-projection-layer fine-tuning with the `(V_m - P_m)` error term and explicitly observe that kNN-MT omits the model's prediction. What appears new relative to those is using it as the actual inference-time memory with a non-dot-product kernel (route match, carried along sequences), on a frozen LM.

## 1. kNN-LM and its variants (key, value, similarity, combination; logit-adding or residual-valued variants)

### Takeaway
Every kNN-LM-family method surveyed stores (dense hidden vector -> next token), scores by a distance kernel on that one position's vector, and combines by **linear interpolation of probabilities**; none stores the model's own predicted distribution, none uses `target - prediction` as the value, and none adds to logits. The closest thing to the NUDGE is an analysis paper (Gao et al. 2023) that writes down the `(one-hot - prediction)` form for output-layer fine-tuning and notes kNN-MT lacks it.

### Cited Findings
- **kNN-LM (Khandelwal et al., ICLR 2020, arXiv 1911.00172) [read].** Datastore: "(K,V) = {(f(c_i), w_i) | (c_i, w_i) in D}". Key = the context vector, specifically "the input to the final layer's feedforward network" (after layer norm). Value = next token. Similarity = squared L2 distance (RBF kernel) over the k retrieved neighbours: `p_kNN(y|x) ∝ Σ 1[y=v_i] exp(-d(k_i, f(x)))`. Combination: `p(y|x) = λ p_kNN(y|x) + (1-λ) p_LM(y|x)`. LM unchanged; one forward pass over the data to build the store. — [Khandelwal et al. 2020](https://ar5iv.labs.arxiv.org/html/1911.00172)
  - Differs from the method: dense final-layer key vs. binary all-layer gate pattern; single-position similarity vs. CARRY; value is the token only (no stored model prediction, so no surprise term); normalised kNN distribution mixed in probability space vs. un-normalised addition to log-probabilities. **Matches:** frozen LM, one write pass per text, token-level store of "what came next".
- **Efficient kNN-LM / adaptive retrieval (He, Neubig, Berg-Kirkpatrick, EMNLP 2021, arXiv 2109.04212) [read].** A small MLP ("retrieval adaptor") models "λ as a function of the context"; "only θ – the parameters of the retrieval adaptor – are updated"; inputs are the LM context embedding, LM confidence, LM entropy, log frequency and fertility of the last 1-4 tokens; output is log λ / log(1-λ). Plus datastore pruning (greedy merging best) and PCA. Still "estimates token distributions by interpolating". — [He et al. 2021](https://ar5iv.labs.arxiv.org/html/2109.04212)
  - Differs: a trained gate on a probability mixture; the method has no gate and no training. Note that LM confidence/entropy enters only as a feature for λ, not as a subtracted prediction.
- **Why do Nearest Neighbor Language Models Work? (Xu, Alon, Neubig, ICML 2023, arXiv 2301.02828) [read].** Generalises kNN-LM as a second softmax layer over a huge "embedding matrix" (the datastore), mixed with λ. Three reasons for the gain: "using a different input representation for predicting the next tokens" (the attention-layer output as query "is crucial"), "approximate kNN search", and "the importance of softmax temperature for the kNN distribution". Adding more embedding rows per word recovered only part of the gain. They trained with an interpolated loss in probability space; no logit-space combination and no residual/error-valued store is tested. — [Xu et al. 2023](https://ar5iv.labs.arxiv.org/html/2301.02828)
  - Relevance: supports the idea that a key that is a *different view* from the output-layer input helps; does not anticipate binary keys, CARRY, or NUDGE.
- **kNN-MT (Khandelwal et al., ICLR 2021, arXiv 2010.00710) [abstract].** "predicts tokens with a nearest neighbor classifier over a large datastore of cached examples", "representations from a neural translation model for similarity search", "requires no additional training". — [kNN-MT](https://arxiv.org/abs/2010.00710). (Background knowledge, not re-verified here: decoder hidden state key, target-token value, probability interpolation as in kNN-LM.)
- **kNN-MT as implicit gradient descent on the output layer (Gao et al., EMNLP 2023, arXiv 2305.13034) [read; the page's math rendering was garbled, formulas below are paraphrased].** Abstract: kNN-MT is "an efficient technique to implicitly execute gradient descent on the output projection layer of NMT", "indicating that it is a specific case of model fine-tuning". They treat the kNN distribution as "a key-value memory with attention storing all nearest neighbors from the datastore", with keys = stored context vectors and values = one-hot target tokens. They state kNN-MT "solely utilizes the label of k-nearest-neighbors as error signals to update the models, without considering the prediction of the NMT model"; the one-hot-minus-prediction term `(V_m - P_m)` appears in their explicit output-projection-layer fine-tuning derivation (Eq. 14), which they compare against kNN-MT. The equivalence holds under a relaxed linear-attention approximation; the final predictor is still the probability interpolation rewritten as `p_NMT + λ(p_kNN - p_NMT)`. — [Gao et al. 2023](https://ar5iv.labs.arxiv.org/html/2305.13034)
  - **Closest published statement to the NUDGE.** It contains (a) the dual-form reading of a retrieval memory as an output-layer gradient step and (b) the explicit recognition that the true gradient value is label minus model prediction and that kNN methods drop the prediction. It does not build a memory that stores the prediction and adds the residual to logits; it uses the view for analysis and for comparing against real fine-tuning (weights changed).
- **kNN-Adapter (Huang et al., arXiv 2302.10879) [abstract].** Adapts "black-box large language models"; "adaptively learns to interpolate the output of the language model with retrieval results from a datastore consisting of the target domain data". — [kNN-Adapter](https://arxiv.org/abs/2302.10879). Trained interpolation weight; still interpolation.
- **kNN-Prompt (Shi et al., EMNLP 2022, arXiv 2205.13792) [abstract].** "a simple and effective kNN-LM with automatically expanded fuzzy verbalizers", GPT-2 large, zero-shot. — [kNN-Prompt](https://arxiv.org/abs/2205.13792). A kNN-LM applied to classification; no new key, carry or residual value.
- **Adaptation Approaches for Nearest Neighbor LMs (Bhardwaj et al., arXiv 2211.07828) [read].** Three approaches: "adapting the underlying LM (using Adapters)", "expanding neighborhood retrieval over an additional adaptation datastore", "adapting the weights (scores) of retrieved neighbors using a learned Rescorer module" (`s_i^r = f^r([c_i, c_q, w_i, x_i])`, `s_i' = s_i^r - s_i`). Final combination is still `λ p_kNN + (1-λ) p_LM`. — [Bhardwaj et al. 2022](https://ar5iv.labs.arxiv.org/html/2211.07828)
- **Plug-and-play knowledge distillation for kNN (search result only) [search only].** A datastore "(K, V, U) that stores context vectors, hard targets and teacher logits". This is the only kNN store found that keeps a *distribution/logits* beside the target, but it is a teacher's logits used as a soft target, not the base model's own prediction subtracted as a residual. — [AACL 2022 short paper 57 (preview)](https://preview.aclanthology.org/fix_video/2022.aacl-short.57.pdf)
- **MLP Memory (arXiv 2508.01832) [abstract].** "pretraining an MLP to imitate a kNN retriever's behavior on the entire pretraining dataset", combined by "simple probability interpolation", "without explicit document access". — [MLP Memory](https://arxiv.org/abs/2508.01832). Parametric and trained; opposite design choice to the method.
- Two targeted searches for a kNN-LM variant that adds to logits or stores `target minus prediction` returned no such paper; the search summaries say so explicitly. — [kNN-LM](https://arxiv.org/pdf/1911.00172), [Bhardwaj et al.](https://arxiv.org/pdf/2211.07828), [He et al.](https://arxiv.org/pdf/2109.04212)

### Inferences
- The combination rule is a real point of difference from the kNN-LM family: all of them produce a normalised `p_kNN` and mix probabilities, so a memory can never push a token *down* except by diluting it. The NUDGE subtracts the stored prediction, so it lowers tokens the model wrongly favoured at the stored place. Gao et al.'s own remark (kNN-MT ignores the model's prediction) is the published acknowledgement of exactly this gap.
- Storing the model's own predicted distribution per datastore entry was not found in any kNN-LM variant.
- If the model predicted the stored token perfectly, `told - predicted = 0` and the entry contributes nothing; no kNN-LM variant has this self-silencing property (He et al.'s λ-network approximates it with a trained gate).

### Gaps
- kNN-MT, kNN-Prompt and kNN-Adapter were verified at abstract level only; their exact formulas were not re-read.
- I did not verify KSTER (kernel-smoothed MT), adaptive kNN-MT (Zheng et al. 2021), "kNN-LM does not improve open-ended text generation" (Wang et al. 2023), or chunk-based kNN-MT (Martins et al. 2022); none is known to me to use a residual value or logit addition, but that is unverified.
- No exhaustive check of 2025-2026 kNN-LM papers was possible; "Long-Tail Crisis in Nearest Neighbor Language Models" (arXiv 2503.22426) and "From Lookups to Lessons" (arXiv 2611.00450) surfaced in search but were not read.

## 2. RetoMaton and methods that carry pointers / match state along stored sequences (∞-gram, NEST, Copy-is-All-You-Need, NPM); soft alignment kernels

### Takeaway
RetoMaton is the nearest relative of CARRY in structure (state persists along stored sequences) but it is a **hard, gated, thresholded pointer set with per-step scores recomputed from the current hidden state**, not an accumulated similarity; ∞-gram and NEST carry exact matches with back-off or acceptance thresholds. No retrieval LM was found that uses a soft-alignment / string-kernel recurrence like `P_t[n] = sim^scale * (1 + P_(t-1)[n-1])` as the retrieval score.

### Cited Findings
- **RetoMaton (Alon, Xu, He, Sengupta, Roth, Neubig, ICML 2022, arXiv 2201.12431) [read].** Each entry is stored as "(f(c_i), w_i, p_i)" where `p_i` points to the next entry in the corpus. Keys are clustered (k-means) into automaton states; "the entries' pointers are the state's allowed outgoing transitions". Transition: `δ(q, w) = { π(ρ(p_i)) | (·, w_i, p_i) ∈ π^-1(q), w_i = w }` — pointers are followed **only from entries whose stored token equals the token actually generated**. Restart rule: if the number of continuing states `|δ̂| ≥ τ` no search is done, otherwise a fresh kNN search is run and its results are unioned in. Score: `φ(q, c, w) = Σ exp(-dist(f(c), k_i))` over the entries of the state with value `w`, i.e. distances are **recomputed at each step from the current hidden state**; `p_auto(w|c,S) ∝ Σ_{q∈S} φ(q,c,w)`. Combination: `p = λ p_auto + (1-λ) p_LM`. What persists across steps is the active state set, not a weight. No training other than clustering. — [Alon et al. 2022](https://ar5iv.labs.arxiv.org/html/2201.12431)
  - Component-by-component vs. CARRY: (i) RetoMaton carries *which* entries are live (a set); the method carries *how much* each entry is live (a real number that compounds). (ii) RetoMaton's continuation is conditioned on an exact token match `w_i = w` (a hard gate); the method has no token-match gate, only route similarity. (iii) RetoMaton has a threshold τ and a restart search; the method has none. (iv) RetoMaton's per-step score is single-step distance; the method's score is a sum over all aligned runs of products of per-token similarities. (v) RetoMaton's purpose is to *save searches*; the method compares against everything every step and uses the carry as the score itself. **Shared idea:** exploit the corpus order, i.e. the entry after a matched entry is a likely match for the next step.
- **∞-gram / Infini-gram (Liu, Min, Zettlemoyer, Choi, Hajishirzi, 2024, arXiv 2401.17377) [read].** `P_∞(w_i | w_1:i-1) = cnt(context + w_i) / cnt(context)` with the context being the longest suffix with non-zero count; "we backoff only when the denominator is zero"; effective n is "one plus the length of the prompt's longest suffix that appears in the training data". Suffix array over the tokenised corpus. Combination: `P = λ P_∞ + (1-λ) P_neural`, with two λ's (sparse vs. non-sparse estimates). Matching is exact token matching only. — [Liu et al. 2024](https://ar5iv.labs.arxiv.org/html/2401.17377)
  - Relation to CARRY: with hard 0/1 similarity, `P_t[n]` in the method equals the length of the exact run ending at `n`, so the ∞-gram's longest-suffix match is the hard-similarity, winner-take-all limit of CARRY. Differences: ∞-gram keeps only the *longest* match (back-off), counts tokens, is symbolic (token identity, not model state), and interpolates probabilities; CARRY sums over all run lengths with soft per-token similarity and never backs off.
- **NEST, Nearest Neighbor Speculative Decoding (Li et al., 2024, arXiv 2405.19325) [read].** Frozen LM (Llama-2-chat), passage retrieval then token-level kNN (squared L2, top 1024); mixture `λ_t p_LM + (1-λ_t) p_kNN` with λ_t from a "relative retrieval confidence" sigmoid; if confidence is low for the LM, drafts an n-gram (n = 64) continuing from the retrieved token's corpus position; each draft token accepted with probability `min(1, p_M(token) / (γ · max p_M))`, cut at the first rejection. — [Li et al. 2024](https://ar5iv.labs.arxiv.org/html/2405.19325)
  - Carries a hard span from one source position with accept/reject thresholds; not a soft score over all stored positions.
- **Copy is All You Need / CoG (Lan et al., ICLR 2023, arXiv 2307.06962) [read].** Generation as "a series of copy-and-paste operations"; a phrase table of (phrase, vector) with phrase vector = start/end token representations from a BERT-based phrase encoder; prefix encoded by a GPT-2-based encoder; fitness = dot product; trained with InfoNCE plus token-level loss; no token-by-token tracking of alignment at inference. — [Lan et al. 2023](https://ar5iv.labs.arxiv.org/html/2307.06962)
  - Trained, phrase-level, single-shot retrieval; differs on every component.
- **NPM (Min et al., 2023, arXiv 2212.01349) [abstract].** "replaces this softmax with a nonparametric distribution over every phrase in a reference corpus", "fills in the [MASK] solely from retrieving a token from a text corpus", trained "with a contrastive objective". — [NPM](https://arxiv.org/abs/2212.01349). Trained masked LM; not comparable in mechanism.
- Soft-alignment search: an extended search for a Smith-Waterman / soft n-gram / sequence-kernel retrieval score in non-parametric LMs returned nothing on point; the only alignment-kernel hit was a DTW-style kernel over hidden-state sequences for multimodal retrieval (not an LM memory). — [NeurIPS 2024 paper (search hit)](https://proceedings.neurips.cc/paper_files/paper/2024/file/29416b66c2149872b9d1415a3fd2c5e0-Paper-Conference.pdf)
- A second extended search for an accumulated/continuation-bonus match score along stored sequences returned only RetoMaton, with the summary noting no accumulated score was found. — [RetoMaton (PMLR)](https://proceedings.mlr.press/v162/alon22a/alon22a.pdf)

### Inferences
- CARRY unrolled is `P_t[n] = Σ_{L≥1} Π_{j=0..L-1} s_(t-j)[n-j]`: a sum over all contiguous aligned run lengths of the product of per-token similarities. This is the gap-free form of a local-alignment / all-substrings sequence kernel computed along one diagonal. I found no LM-retrieval paper using it; RetoMaton, ∞-gram and NEST are its hard, thresholded cousins. This is the component with the weakest prior-art coverage in this literature.
- A reviewer will most likely frame CARRY as "a soft RetoMaton" or "a soft ∞-gram in activation space"; the notes above give the exact five differences from RetoMaton to pre-empt that.

### Gaps
- The string-kernel / alignment-kernel literature itself (e.g. all-substrings kernels, local alignment kernels) was not searched as primary sources; the statement that CARRY has that form is my inference, with no citation.
- Chunk-based kNN-MT, "Simple and Scalable Nearest Neighbor MT", suffix-automaton LMs other than ∞-gram, and copy-generator follow-ups were not verified.
- NEST's page was read only to 100k characters (appendix unread).

## 3. Continuous cache, unbounded cache, pointer sentinel

### Takeaway
The neural cache is the oldest version of "store (hidden state, next token), score by similarity to the current state, no training", and its "global normalisation" variant is the nearest published thing to combining in score space, but it is a log-sum-exp over cache and vocabulary terms with token-valued entries, not an additive residual.

### Cited Findings
- **Continuous cache (Grave, Joulin, Usunier, ICLR 2017, arXiv 1612.04426) [read].** "the cache stores pairs (h_i, x_i+1) of a hidden representation" and the following word. `p_cache(w | h_1..t, x_1..t) ∝ Σ_i 1{w = x_(i+1)} exp(θ h_t^T h_i)`. Linear interpolation `(1-λ) p_vocab + λ p_cache`, or global normalisation `p(w) ∝ exp(h_t^T o_w) + Σ_i 1{w = x_(i+1)} exp(θ h_t^T h_i + α)`, "a softmax over the vocabulary and the words in the cache". No cache-specific training; θ, λ/α tuned on validation. The paper does not discuss gradient-based adaptation. — [Grave et al. 2017](https://ar5iv.labs.arxiv.org/html/1612.04426)
  - Differs: dense last-layer key, dot-product single-position similarity, token value, no stored prediction. Global normalisation = `logsumexp(logit_w, cache_score_w)`, not `logit_w + η·Σ P·(told - predicted)`; it can only raise cached words. **Matches:** inference-time only, frozen model, all past positions scored without top-k, a scalar sharpness (θ ≈ the method's `scale`).
- **Unbounded cache (Grave, Cisse, Joulin, NeurIPS 2017, arXiv 1711.02604) [abstract].** Extends "continuous cache models" to a large non-parametric memory of all past hidden activations using "approximate nearest neighbor search and quantization algorithms"; "improves the perplexity of pre-trained language models on new distributions". — [Grave et al. 2017b](https://arxiv.org/abs/1711.02604)
- **Pointer sentinel mixture (Merity et al., ICLR 2017, arXiv 1609.07843) [abstract].** "the ability to either reproduce a word from the recent context or produce a word from a standard softmax classifier". — [Merity et al. 2017](https://arxiv.org/abs/1609.07843). (Background knowledge, not re-verified: the pointer is trained attention and a learned sentinel gate sets the mixture weight; it is a trained probability mixture.)
- **Dynamic evaluation vs. the cache (Krause et al., ICML 2018, arXiv 1709.07432) [read].** "The neural cache closely relates to dynamic evaluation"; "The main difference is the mechanism used to fit to recent history" (non-parametric nearest-neighbour-like vs. gradient descent on parameters); the cache learns "a type of non-parametric output layer on the fly at test time"; "One drawback of the neural cache method is that it cannot adjust the recurrent hidden state dynamics". The paper does not state an equivalence and does not use the term fast weights. — [Krause et al. 2018](https://ar5iv.labs.arxiv.org/html/1709.07432)
  - Dynamic evaluation changes weights; the method does not. But the method's own description ("one gradient step on the output weights per stored token, kept in dual form") places it between these two: a cache whose values are dynamic-evaluation error signals.

### Inferences
- The method can be described fairly as "a neural cache whose value is the dynamic-evaluation error signal for the output layer, with a different kernel". Both halves are 2017-2018 ideas; the published bridge between them is the dual-form literature in section 6.

### Gaps
- Pointer sentinel and unbounded cache formulas were not re-read (abstract only).

## 4. Memorizing Transformers, TRIME, SPALM, Unlimiformer (kNN-attention memories)

### Takeaway
These inject retrieved memories **inside** the network (attention) or in a jointly normalised output softmax and, except Unlimiformer, require training; none uses binary keys, a carried sequence score, or a residual value.

### Cited Findings
- **Memorizing Transformers (Wu, Rabe, Hutchins, Szegedy, ICLR 2022, arXiv 2203.08913) [read].** External memory of attention "(key, value) pairs" from past inputs; approximate kNN (top 32) in one layer near the top; combined with local attention by a learned per-head gate `V_a = V_m ⊙ g + V_c ⊙ (1-g)`; "gradients are not backpropagated into the external memory"; model and gate are trained. — [Wu et al. 2022](https://ar5iv.labs.arxiv.org/html/2203.08913)
  - Differs: keys/values are attention projections, combination is inside a layer, model is trained with the memory.
- **TRIME (Zhong, Lei, Chen, EMNLP 2022, arXiv 2205.12674) [read].** `P(w|c) ∝ exp(E_w^T f_θ(c)) + Σ_{(c_j,x_j)∈M, x_j=w} exp(sim(g_θ(c), g_θ(c_j)))`, `sim(q,k) = q·k/√d`; one joint normalisation in training; with a large external memory at test time a separate memory distribution is interpolated with λ; all parameters trained. — [Zhong et al. 2022](https://ar5iv.labs.arxiv.org/html/2205.12674)
  - Same functional form as Grave's global normalisation (sum of exponentials), token-valued, trained. Not a logit-additive residual.
- **SPALM (Yogatama, d'Autume, Kong, TACL 2021, arXiv 2102.02557) [abstract].** Combines "a large parametric neural network" with "a non-parametric episodic memory component"; "We design a gating function to adaptively combine multiple information sources to make a prediction." — [Yogatama et al. 2021](https://arxiv.org/abs/2102.02557). (Background knowledge, not re-verified: the gate is trained and mixes hidden representations rather than output probabilities.)
- **Unlimiformer (Bertsch, Alon, Neubig, Gormley, NeurIPS 2023, arXiv 2305.01625) [abstract].** "wraps any existing pretrained encoder-decoder transformer", "offloads the cross-attention computation to a single k-nearest-neighbor (kNN) index", "the returned kNN distances are the attention dot-product scores", "without additional learned weights". — [Bertsch et al. 2023](https://arxiv.org/abs/2305.01625)
  - Training-free like the method, but it is a long-input mechanism for cross-attention, not a next-token memory at the output.

### Inferences
- None of these threatens novelty of any of the three components; they are relevant only as the "attention-side" alternative that a reviewer will ask the method to be compared against.

### Gaps
- SPALM and Unlimiformer internals not re-read.

## 5. Modern Hopfield networks and sparse distributed memory

### Takeaway
Hopfield/SDM work supplies the theory that attention is an associative memory and (for SDM) that binary addresses with Hamming-distance reads are a classical memory design, but I found no work that uses a transformer's own MLP on/off patterns as SDM/Hopfield addresses for a next-token memory.

### Cited Findings
- **Hopfield Networks is All You Need (Ramsauer et al., ICLR 2021, arXiv 2008.02217) [abstract].** "a modern Hopfield network with continuous states and a corresponding update rule"; "can store exponentially (with the dimension of the associative space) many patterns", "retrieves the pattern with one update"; "The new update rule is equivalent to the attention mechanism used in transformers." — [Ramsauer et al. 2020](https://arxiv.org/abs/2008.02217)
  - Continuous states, softmax retrieval of the stored pattern itself (auto-/hetero-association), used as a trainable layer. The method's read is un-normalised and its value is an error vector, not a pattern.
- **Attention Approximates Sparse Distributed Memory (Bricken & Pehlevan, NeurIPS 2021, arXiv 2111.05498) [abstract].** Attention "can be closely related under certain data conditions to Kanerva's Sparse Distributed Memory (SDM)", "a biologically plausible associative memory model". — [Bricken & Pehlevan 2021](https://arxiv.org/abs/2111.05498). (Background knowledge, not re-verified here: Kanerva's SDM uses binary addresses and reads all locations within a Hamming radius; the paper shows the resulting weighting is approximately exponential in similarity, i.e. softmax-like.)
  - Relevance to KEY: SDM is the classical precedent for *binary address + Hamming similarity + un-thresholded power/exponential weighting*. The method's `sim^scale` on the share of equal bits is the same family of read weighting. What SDM work does not do is take the addresses from a frozen LM's gate pattern.
- **Sparse Distributed Memory is a Continual Learner (Bricken et al., ICLR 2023, arXiv 2303.11934) [abstract].** "we create a modified Multi-Layered Perceptron (MLP) that is a strong continual learner", "free from any memory replay or task information", "novel methods to train sparse networks". — [Bricken et al. 2023](https://arxiv.org/abs/2303.11934). A trained MLP variant for continual learning; the abstract reports no language-model memory.

### Inferences
- A reviewer versed in SDM would recognise KEY + `sim^scale` as an SDM-style read over binary addresses; the novelty claim for KEY should be "the address is the frozen LM's own all-layer MLP gate pattern", not "binary keys with Hamming similarity" in general.

### Gaps
- The Hopfield update formula and SDM's Hamming-radius read were not re-read from the primary texts in this session.
- Hopfield layers used as an *output-side* LM memory (if any exist) were not found or verified.

## 6. Retrieval memories whose value is an error / residual / correction (and the "dual form" claim)

### Takeaway
The identity behind the NUDGE is published: a GD-trained linear layer equals its initial weights plus un-normalised attention over stored inputs with **error signals as values** (Irie et al. 2022), fast weight layers implement exactly that as linear attention with gradient values (Clark et al. 2022), and Gao et al. 2023 write the output-layer case with `(label - prediction)`. None of them uses it as a training-free inference-time memory on a frozen LM with a non-dot-product kernel.

### Cited Findings
- **The Dual Form of Neural Networks Revisited (Irie, Csordás, Schmidhuber, ICML 2022, arXiv 2202.05798) [read].** "Linear layers in neural networks (NNs) trained by gradient descent can be expressed as a key-value memory system"; the output for a test input is the initial-weight term plus un-normalised dot-product attention over stored training inputs (keys) and error signals (values). Applied to small LSTM language models (character-level book, WikiText-2) as an **analysis/visualisation tool**; the authors note that storing all training data is impractical in regular settings; keys and values are real-valued. — [Irie et al. 2022](https://ar5iv.labs.arxiv.org/html/2202.05798)
  - Exactly the method's claimed equivalence, for a general linear layer. For a softmax output layer the error signal is `one-hot - predicted` (standard cross-entropy gradient), which is the method's stored value. Differences: the kernel there is necessarily the dot product of the layer's inputs (`h_t · h_i`), which is what a real gradient step gives; the method substitutes carried route similarity, so it is **no longer equal to any actual gradient step on the output weights** — it is the dual form with a replaced kernel.
- **Meta-Learning Fast Weight Language Models (Clark, Guu, Chang, Pasupat, Hinton, Norouzi, EMNLP 2022, arXiv 2212.02475) [read].** `o'_t = v'_t W − α_W Σ_{i<t} v'_t v_i^T ∇_{o_i} L_i`; the sum "can be interpreted as linear attention (i.e., without a softmax) using query v'_t, keys v_i, and values ∇_{o_i} L_i." The fast weight layer sits on top of the transformer before the softmax; a "Bias Only" ablation applies fast weights only to the softmax bias. Trained: "jointly optimizes the transformer, softmax, and FWL parameters, as well as the step sizes α". Framed as giving "the benefits of dynamic evaluation" cheaply. — [Clark et al. 2022](https://ar5iv.labs.arxiv.org/html/2212.02475)
  - **Close match on the NUDGE's form** (un-normalised attention, gradient-valued memory, added to pre-softmax outputs, causal sum over past positions). Differences: meta-learned (second-order training) vs. no training; dot-product keys vs. binary route keys with CARRY; memory limited to the current context window vs. a persistent store of told prompts; the paper does not write the value as one-hot minus prediction.
- **Gao et al. 2023 (see section 1) [read].** The `(V_m − P_m)` term for output-projection fine-tuning and the remark that kNN-MT uses labels "without considering the prediction of the NMT model". — [Gao et al. 2023](https://ar5iv.labs.arxiv.org/html/2305.13034)
- **Dynamic evaluation (Krause et al. 2018) [read].** Real gradient updates at test time; weights change. — [Krause et al. 2018](https://ar5iv.labs.arxiv.org/html/1709.07432)
- **Test-time training on nearest neighbours (Hardt & Sun, 2023, arXiv 2305.18466) [abstract].** "For each test input, our system retrieves its neighbors and fine-tunes the model on their text", "retrieving and training on as few as 20 neighbors, each for only one gradient iteration". — [Hardt & Sun 2023](https://arxiv.org/abs/2305.18466)
  - Retrieval plus one real gradient step per neighbour on the whole model; weights change (temporarily). The method is the output-layer-only, dual-form, weights-untouched analogue with similarity weighting in place of hard top-k.
- "Irie & Gershman 2025" review of fast weight programmers and Ba et al. 2016 (attention as fast weights) surfaced in search only and were not read. — [search hit: arXiv 2508.08435](https://arxiv.org/pdf/2508.08435v2) [search only]

### Inferences
- The sentence "equivalent to one gradient step on the output weights per stored token kept in dual form" should not be claimed as a contribution; it is Irie et al.'s Corollary applied to the unembedding, and Gao et al. and Clark et al. already connect it to retrieval memories and to LMs. Strictly, it is only an exact equivalence if the similarity were `h_t · h_i`; with route similarity and CARRY it is an analogy.
- What I could not find published: a retrieval LM that (1) stores the frozen model's predicted distribution at write time, (2) uses `told − predicted` as the retrieved value, and (3) adds the weighted sum to log-probabilities with no normalisation, with no training. Each neighbour does one or two of these: Gao (derives it, uses it for analysis and real fine-tuning), FWL (does it inside a context window with meta-training), PP-KD datastore (stores logits, but a teacher's).
- "Only surprise pushes" has a published near-synonym in He et al.'s learned λ (less retrieval weight when the LM is confident), but there it is a trained gate, here it falls out of the value.

### Gaps
- I did not find, and so cannot rule out, a paper titled around "residual kNN" / "nearest neighbour calibration" that stores residuals; two targeted searches returned nothing. Absence in search is weak evidence.
- Gao et al.'s equations were paraphrased from a garbled render; the exact Eq. 14 should be checked in the PDF before quoting it in a paper.
- von Oswald et al. / Dai et al. (in-context learning as gradient descent, dual form) belong to an adjacent scope and were not read here.

## 7. Has any of these used binary activation patterns as keys?

### Takeaway
No. Every retrieval/cache LM memory surveyed keys on a dense real-valued vector (final-layer FFN input, attention output, attention key projection, phrase-encoder vector) or on exact tokens; no work was found that keys a language-model memory on the on/off pattern of all MLP units across all blocks.

### Cited Findings
- kNN-LM key = dense "input to the final layer's feedforward network"; — [Khandelwal et al. 2020](https://ar5iv.labs.arxiv.org/html/1911.00172). Xu et al.: best key is the dense attention-layer output — [Xu et al. 2023](https://ar5iv.labs.arxiv.org/html/2301.02828). RetoMaton: same dense keys, clustered — [Alon et al. 2022](https://ar5iv.labs.arxiv.org/html/2201.12431). Memorizing Transformers: attention key vectors — [Wu et al. 2022](https://ar5iv.labs.arxiv.org/html/2203.08913). ∞-gram: exact token suffixes — [Liu et al. 2024](https://ar5iv.labs.arxiv.org/html/2401.17377).
- A targeted search for ReLU-mask / binary-activation-pattern keys with Hamming similarity in kNN-LMs returned no such memory. What exists separately: on/off pattern encodings of DNNs as a *representation* (neuron marked 1 if activation > 0) — [On-Off Pattern Encoding, arXiv 2401.09518](https://arxiv.org/pdf/2401.09518) [search only]; activation patterns as elements of a binary hypercube with Hamming distance, for geometry analysis — [On Space Folds of ReLU Neural Networks, arXiv 2502.09954](https://arxiv.org/pdf/2502.09954) [search only].
- A second extended search (2025-2026 terms) found activated-neuron overlap used as a lookup signal for **pre-training-data detection**, not generation — [arXiv 2507.16414](https://arxiv.org/pdf/2507.16414) [search only]; and trained parametric memories for frozen LLMs (not activation-keyed) — [arXiv 2603.22329](https://arxiv.org/pdf/2603.22329), [arXiv 2611.00450](https://arxiv.org/pdf/2611.00450) [search only].
- SDM is the classical binary-address, Hamming-similarity memory and has been tied to attention — [Bricken & Pehlevan 2021](https://arxiv.org/abs/2111.05498) — but with learned/random addresses, not a frozen LM's gate pattern.

### Inferences
- Within this literature KEY appears unpublished. The prior art most likely to bear on it lives outside this scope: activation-pattern / linear-region / neural-tangent-kernel-style similarity work (the share of equal gates across all units is closely related to path/gate kernels), and binary hashing of dense keys for kNN efficiency. Another researcher's scope should cover those; this note only establishes that the retrieval-LM literature does not use it.
- Binary quantisation of *dense* keys for speed (product quantisation in FAISS, used by kNN-LM and the unbounded cache) is a compression of a real-valued key and is not the same thing as using the gate pattern as the key.

### Gaps
- The three [search only] papers above were not read; their relevance is judged from search summaries.
- Locality-sensitive-hashing or binary-code kNN-LM variants (for efficiency) were not specifically verified; I know of none that use the model's native gate pattern.
- Negative results from web search cannot prove absence, especially for 2026 preprints.
