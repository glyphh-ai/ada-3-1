# No published method matches route memory whole

Nothing found in papers, preprints, open-source projects or the few patents that surfaced (search date 2026-11-24, roughly 100 web searches and page reads across five research notes) matches "route memory with surprise nudging" in totality, but the search is a negative result from web search, not a clearance, and only two of the method's three parts look new. **The key (the binary on/off pattern of every MLP unit in every block, per token) was not found as the retrieval key of any language-model memory, and the ungated carried similarity P_t[n] = sim_t[n]^scale · (1 + P_(t-1)[n-1]) was not found as a retrieval kernel anywhere.** The nudge is the weak part of any novelty claim: storing an error signal and applying it by similarity beside frozen weights is the published dual form of gradient descent ([Irie et al. 2022](https://ar5iv.labs.arxiv.org/html/2202.05798)), it was run in primal form on a pretrained LM's softmax layer in 2018 ([MbPA](https://ar5iv.labs.arxiv.org/html/1802.10542)), written as un-normalised attention with gradient values in 2022 ([Fast Weight Layers](https://ar5iv.labs.arxiv.org/html/2212.02475)), and [Gao et al. 2023](https://ar5iv.labs.arxiv.org/html/2305.13034) wrote down the exact (label − prediction) term and noted that kNN retrieval drops it. What was not found is anyone implementing that as a training-free, persistent, non-parametric memory on a frozen pretrained LLM, so that part is defensible only as "not previously implemented or evaluated", never as a new principle. The method's own sentence "one gradient step on the output weights" is not exact once route similarity replaces the hidden-state dot product, and should be reworded before a reviewer does it. The current evidence (Qwen3-0.6B, 60 told sentences, 100% / 97% recall of told text) covers only the column of the standard editing tables where an existing activation-keyed memory already scores 0.93 to 1.00 at 1,000 edits on 7B models ([WISE tables](https://arxiv.org/html/2405.14768v2)). Patent databases could not be queried directly, several of the nearest 2026 preprints (INLAY above all) were read at abstract level only, and OpenReview submissions were not searched; those are the open risks.

## Four questions, four answers: two parts unclaimed, one part already written down

|---|---|---|---|

| (b) Stored (target − stored prediction) applied at the logits by similarity on a frozen pretrained LLM | Not found as an implemented method; the mathematics and a primal-form version are published | Gao 2023, Irie 2022, MbPA 2018, Fast Weight Layers 2022 | Moderate on "not implemented"; high on "the principle is prior art" |
| (c) Ungated carried sequence-alignment similarity as the kernel | Not found | RetoMaton (hard pointers, token-match gate, threshold), ∞-gram (exact longest suffix), NEST (accept/reject spans) | Moderate: string-kernel literature not searched as primary sources |
| (d) The full combination | Not found | kNN-LM overall; GRACE among editors; INLAY on gradient-free logit pushes | Low-to-moderate: no patent clearance, INLAY full text unread |

### (a) Binary on/off patterns are an established similarity measure, but never the key of an LM memory

Every retrieval or cache memory for language models surveyed keys on a dense real-valued vector or on exact tokens: kNN-LM uses the input to the final layer's feed-forward network with squared L2 distance ([Khandelwal et al. 2020](https://ar5iv.labs.arxiv.org/html/1911.00172)), the continuous cache uses the last hidden state with a dot product ([Grave et al. 2017](https://ar5iv.labs.arxiv.org/html/1612.04426)), RetoMaton clusters the same dense keys ([Alon et al. 2022](https://ar5iv.labs.arxiv.org/html/2201.12431)), Memorizing Transformers uses attention key projections ([Wu et al. 2022](https://ar5iv.labs.arxiv.org/html/2203.08913)), and ∞-gram uses exact token suffixes ([Liu et al. 2024](https://ar5iv.labs.arxiv.org/html/2401.17377)). Targeted searches for ReLU-mask or gate-pattern keys with Hamming similarity in kNN-LM-style memories returned no method. **No work was found that uses the gate pattern of all MLP units across all blocks as a memory key.**

The measure itself is not new, and four bodies of work must be cited for it. First, storing binary on/off neuron patterns from training data and comparing a new input's pattern by Hamming distance is published for runtime monitoring and out-of-distribution detection in image classifiers ([Cheng, Nührenberg & Yasuoka 2018](https://arxiv.org/abs/1809.06573); [Olber et al. 2022](https://arxiv.org/abs/2212.14268)); those systems use selected layers, one pattern per input rather than per token, output an accept/reject flag, and retrieve or correct nothing. Second, gates as a kernel is established theory: the Neural Path Kernel is built purely from which gates are on, but it counts paths active for both inputs (on-on only, multiplicative across layers, times the input inner product), is a theory of training on MNIST and CIFAR-10, and gives no retrieval procedure ([Lakshminarayanan & Singh 2020](https://arxiv.org/abs/2006.10529)). Route similarity counts on-on and off-off agreement additively over all units and then raises it to a power, so it is a different function, though a reviewer will expect the citation. Third, Kanerva's sparse distributed memory is the classical memory addressed by Hamming distance between binary codes, and attention has been shown to approximate it ([Bricken & Pehlevan 2021](https://arxiv.org/abs/2111.05498)); sim^scale on a share of equal bits belongs to the same family of read weightings, with the difference that SDM's addresses are given vectors, not a pretrained network's own gate pattern. Fourth, the Hamming agreement of sign bits within one layer estimates an angular similarity (the SimHash property, [DTU notes](https://www2.compute.dtu.dk/courses/02289/2022/approxds/lsh-4x1.pdf)), and Gated Linear Networks explicitly tie half-space gating codes to SimHash ([Veness et al.](https://arxiv.org/abs/1910.01526); [Gated Linear Contextual Bandits](https://ar5iv.labs.arxiv.org/html/2002.11611)); a sceptic can therefore reduce route similarity to "a binarised angular similarity over the concatenated MLP inputs of all blocks". That reduces the measure, not its use.

Inside LLMs, two papers come closest. **MEMOIR (NeurIPS 2025) is the nearest prior use of a sparse binary activation pattern compared by Hamming overlap as a memory address in an LLM**: per edit it computes a top-k mask (k = 4096) of the prompt-averaged input activation at one feed-forward projection, stores every mask, and at inference uses its residual memory only when the query mask's overlap ratio passes a threshold ([Wang et al. 2025](https://arxiv.org/html/2506.07899v4)). It differs on four counts: one layer rather than all, one mask per prompt rather than per token, a hard gate, and gradient-trained content. The other is Balogh's March 2026 study of "binary routing" in GPT-2 Small, which thresholds GELU outputs to fire/not-fire and shows binarisation loses little for the routing decision (79.2% binary versus 78.8% continuous), but analyses a handful of neurons, computes no cross-token similarity and builds no memory, and its consensus structure did not replicate cleanly in GPT-2 Medium or Large ([Balogh 2026](https://arxiv.org/html/2603.10985v1)). It supports the premise and anticipates nothing. Other neuron-pattern work on LLMs uses activated-neuron sets as detectors, not memories ([NA-PDD](https://arxiv.org/pdf/2507.16414)), or predicts the pattern for speed ([Deja Vu](https://arxiv.org/abs/2310.17157)).

### (b) The surprise nudge is a known identity that nobody appears to have run this way

The term (told − predicted) is the cross-entropy gradient at the logits, and each clause of step 3 has a named precedent. Irie, Csordás and Schmidhuber show that a linear layer trained by gradient descent equals its initial weights plus un-normalised dot-product attention over stored inputs with error signals as values, S(x) = W0·x + Σ_t (x_t·x)·e_t; they present it as an analysis tool, call it "not a practical form for regular settings", and say the analysis "is not applicable to models which are already trained" ([Irie et al. 2022](https://ar5iv.labs.arxiv.org/html/2202.05798)). Fast Weight Layers write the output-side case for language models directly: the correction "can be interpreted as linear attention (i.e., without a softmax)" with gradient values, added before the softmax, but the layer is meta-learned jointly with the transformer and lives only inside the current context window ([Clark et al. 2022](https://ar5iv.labs.arxiv.org/html/2212.02475)). **Gao et al. come within one term of the method**: they show kNN-MT implicitly performs gradient descent on the output projection layer, write explicit fine-tuning of that layer with the (V − P) error term, and state that kNN-MT "solely utilizes the label of k-nearest-neighbors as error signals", "without considering the prediction of the NMT model" ([Gao et al. 2023](https://ar5iv.labs.arxiv.org/html/2305.13034)). They never build a datastore of V − P; the residual appears only in their parametric fine-tuning baseline. One caution on this citation: the equations were read from a garbled render and should be checked against the PDF before being quoted.

The closest working method is Memory-based Parameter Adaptation: a pretrained LSTM language model, a memory of (hidden state, next word) pairs written at evaluation time, kernel-weighted gradient steps on the softmax layer's weights, and adapted parameters that "are used for output computation but discarded thereafter" (PTB perplexity 59.6 to 54.3) ([Sprechmann et al. 2018](https://ar5iv.labs.arxiv.org/html/1802.10542)). One MbPA step from the unmodified weights, written out, is the route-memory nudge with kernel w_k·(h_k·h). MbPA differs by materialising temporary weights, recomputing the prediction at query time rather than storing it, using a distance on final hidden states, and adding an L2 pull-back. Hebbian Softmax also writes into the softmax layer from (activation, target) pairs, but at training time, modifying weights, and storing the raw activation rather than the error ([Rae et al. 2018](https://ar5iv.labs.arxiv.org/html/1803.10049)). Dynamic evaluation as published always changes parameters by gradient descent, and its authors contrast it with the neural cache, which "learns a type of non-parametric output layer on the fly at test time" but stores labels, not errors ([Krause et al. 2018](https://ar5iv.labs.arxiv.org/html/1709.07432); [Krause et al. 2019](https://ar5iv.labs.arxiv.org/html/1904.08378)). Test-time training on nearest neighbours takes one real gradient step per retrieved neighbour on all weights ([Hardt & Sun 2024](https://arxiv.org/abs/2305.18466)).

Against that, no kNN-LM variant surveyed stores the base model's own predicted distribution or uses a residual value; all store the next token and interpolate probabilities ([Khandelwal et al. 2020](https://ar5iv.labs.arxiv.org/html/1911.00172); [He et al. 2021](https://ar5iv.labs.arxiv.org/html/2109.04212); [Xu et al. 2023](https://ar5iv.labs.arxiv.org/html/2301.02828); [Bhardwaj et al. 2022](https://ar5iv.labs.arxiv.org/html/2211.07828)). The nearest score-space combination, the cache's global normalisation, is a log-sum-exp that can only raise cached words ([Grave et al. 2017](https://ar5iv.labs.arxiv.org/html/1612.04426)); the nudge can lower a token the model wrongly favoured, and an entry the model already predicted contributes nothing. Among 2026 work on frozen models, logit-side corrections exist but none stores the model's own error: INLAY applies an edit "as a bias added along one token's unembedding direction", gradient-free, with routing ([Singh 2026](https://arxiv.org/abs/2608.26292), abstract only); JitRL adds a retrieved advantage estimate to agent action logits ([Li et al. 2026](https://arxiv.org/pdf/2601.18510v1)); a trained 34M-parameter correction module sits on a frozen Gemma ([Kishore 2026](https://arxiv.org/abs/2609.16145v1)); FAAST builds closed-form fast weights by least squares with no error term, in mid layers for LMs, and loses to kNN-LM on GPT2-XL (15.35 versus 12.70 perplexity) ([Bao et al. 2026](https://arxiv.org/html/2605.04651v2)). **So the implemented object (a persistent external buffer of told-minus-predicted, applied at a frozen LLM's logits through a similarity kernel, ungated and unnormalised, with no training) was not found; the idea that this equals output-layer learning was.**

Two technical caveats belong in any write-up. The dual-form identity forces the kernel to be the dot product of the layer's own inputs; with route agreement the nudge is a functional-gradient step on a virtual linear readout over the route kernel's feature map, not a step on the model's actual unembedding. And because every stored error is computed against the frozen model, repeated or redundant told tokens push additively, where true sequential dynamic evaluation would push less the second time. That is a behavioural difference to test, not only a framing point.

### (c) The carry is the least-covered part, with hard-edged cousins

RetoMaton is the nearest relative in structure: each datastore entry keeps a pointer to its successor, and generation traverses the resulting automaton ([Alon et al. 2022](https://ar5iv.labs.arxiv.org/html/2201.12431)). It differs in five specific ways. It carries which entries are live (a set), not how strongly each is live (a compounding number). Its pointers are followed only from entries whose stored token equals the token actually generated, a hard gate. It has a threshold on the number of continuing states and a restart search. Its per-step score is recomputed from the current hidden state alone. Its purpose is to save up to 83% of nearest-neighbour searches, not to serve as the score. The ∞-gram model is the hard, winner-take-all limit of the carry: it conditions on the longest exactly matching suffix and backs off only when the count is zero ([Liu et al. 2024](https://ar5iv.labs.arxiv.org/html/2401.17377)); with 0/1 similarity the route-memory recurrence gives exactly the length of the exact run ending at a stored position. NEST continues stored spans with accept/reject thresholds and a normalised mixture ([Li et al. 2024](https://ar5iv.labs.arxiv.org/html/2405.19325)), and EM-LLM retrieves contiguous events back into the context window ([EM-LLM](https://github.com/em-llm/EM-LLM-model)).

Unrolled, the recurrence is a sum over all contiguous aligned run lengths of the product of per-token similarities: a gap-free local-alignment score, the structure of an all-substrings string kernel or Smith-Waterman without gaps. That characterisation is this report's own reasoning, not a cited result, and the string-kernel literature was not searched as primary sources. Extended searches for a soft-alignment or accumulated continuation score in non-parametric LMs returned only RetoMaton. **The honest position: "a match that continues a previous match counts more" is established; the soft, multiplicative, ungated form over activation-pattern similarity was not found.** A reviewer will call it "a soft RetoMaton" or "a soft ∞-gram in activation space", so it is a design detail to claim narrowly, not a headline.

### (d) The whole combination, and the "through the weights" variant

No single source does all three steps on a frozen model without training. The 2025-2026 "learning at inference" work splits into bins that route memory sits outside: architectures trained from scratch with gradient-updated memory modules, such as Titans, whose "surprise" is the gradient of an internal key-value reconstruction loss of a learned memory MLP whose weights are rewritten at test time ([Behrouz et al. 2025](https://arxiv.org/html/2501.00663v1)); per-corpus trained memories such as Memory Decoder ([Cao et al. 2025](https://arxiv.org/html/2508.09874v1)); trained adapters on a frozen Qwen3-4B ([Prometheus Mind](https://arxiv.org/abs/2601.15324)); steering-vector memories keyed on a whitened conversation gist and gated on a match ([Jumle 2026](https://arxiv.org/abs/2610.14958), abstract only); and text-level agent memories, which is also where the two LLM-memory patents that surfaced sit ([US 2026/0111708 A1](https://patents.google.com/patent/US20260111708A1/en); [US 12,731,052 B1](https://www.patents-review.com/a/19403747-large-language-model-memory-episodic-temporal-reasoning.html)). No open-source project was found that stores neuron firing patterns as an inference-time memory for a local LLM.

The earlier variant that scored every vocabulary token's first-block activation pattern against the stored next route also turned up nothing: the nearest things run candidates forward and score them by activation-based confidence ([CoDec-style decoding](https://arxiv.org/html/2406.13230)) or project a hidden state through the output head. The embedding-inversion and hidden-state-inversion literature was not searched, so that variant cannot be called new yet.

| Continuous cache ([2017](https://ar5iv.labs.arxiv.org/html/1612.04426)) | Frozen, training-free, all past positions scored, a sharpness scalar | Dense key, dot product, token value; log-sum-exp or interpolation, can only raise cached words |

| MbPA ([2018](https://ar5iv.labs.arxiv.org/html/1802.10542)), closest on the nudge | Pretrained LM, test-time memory, kernel-weighted softmax-layer gradient | Temporary real weights, prediction recomputed not stored, hidden-state distance kernel, LSTM, pull-back term |
| Gao et al. ([2023](https://ar5iv.labs.arxiv.org/html/2305.13034)) | States retrieval = output-layer gradient step; names the missing prediction term | Analysis of kNN-MT; residual used only in parametric fine-tuning |

| GRACE ([2023](https://arxiv.org/pdf/2211.11031)), closest editor | Frozen weights, activation-keyed external store, edits appended | One layer's continuous key, epsilon-ball deferral gate, value trained by backprop, replaces a hidden state |
| MEMOIR ([2025](https://arxiv.org/html/2506.07899v4)), closest on the key | Sparse binary activation mask compared by Hamming overlap | One layer, per-prompt mask, threshold gate, gradient-trained residual memory |
| INLAY ([2026](https://arxiv.org/abs/2608.26292)) | Frozen, gradient-free, decode-time push in unembedding space | Pushes a target token's direction, not an error; has routing with abstention; key source not stated in the abstract |
| Titans ([2025](https://arxiv.org/html/2501.00663v1)) | "Only prediction error writes" | Hidden-space reconstruction error, memory MLP weights rewritten, momentum and forgetting, trained end to end |
| Saka ([2026](https://arxiv.org/html/2610.33025)) | Frozen Qwen3, inference-time, error-driven, "learns while it reads" intent | Real SGD steps on late MLP projections, no store, no key; reports that facts do not bind |

The Saka preprint deserves attention because it is the negative result a reviewer will cite against the idea: one SGD step per 128-token chunk on otherwise frozen Qwen3-1.7B and Qwen3-4B lowers loss 5 to 8% but recovers essentially none of the accuracy lost to truncation on eight retrieval benchmarks, and writing facts with next-token loss "stored the training format more than the fact"; the paper says retrieval needs "a key-to-value binding that a handful of SGD steps on a late projection does not form" ([Saka 2026](https://arxiv.org/html/2610.33025)). Route memory's reply is that an explicit keyed store is exactly such a binding, which makes the comparison a selling point only if it is run.

## Three claims hold up; five will be struck down

A paper can safely say, with "to our knowledge" and the search limits stated, that no prior work uses the binary gate pattern of all MLP units across all blocks of a pretrained LM as the key of a non-parametric memory; that no prior work was found using an ungated soft carried alignment score over stored sequences as the retrieval kernel of an LM memory; and that the combination (route key, carried kernel, stored told-minus-predicted added un-normalised to a frozen model's log-probabilities, no training, no gate) was not found. A fourth claim is safe in a weaker form: a persistent, training-free store of the model's own output residuals on a frozen pretrained transformer was not found implemented or evaluated. It is also fair to say route memory is structurally immune to the sequential-edit weight collapse documented for ROME and MEMIT, since it never writes weights ([Gupta et al. 2024](https://arxiv.org/html/2401.07453v4); [Yang et al. 2024](https://aclanthology.org/2024.findings-acl.322)).

A paper cannot safely claim that Hamming similarity of activation patterns is new (Cheng 2018, Olber 2022, MEMOIR 2025, SDM), that gates as a kernel are new (the Neural Path Kernel), that a training-free token datastore correcting a frozen LM is new (kNN-LM, the cache), that following stored sequences is new (RetoMaton, ∞-gram), or that "store the error and apply it by similarity instead of changing weights" is a new principle (Irie, Clark, Gao, MbPA). "Only surprise pushes" is the ordinary property of any cross-entropy gradient on the softmax layer and MbPA notes its consequence in words. **"Exactly one gradient step on the output weights" is false as stated once the kernel is route similarity**; the accurate sentence is "the dual form of one output-layer gradient step per memory, with the hidden-state kernel replaced by carried route agreement". The word "surprise" will send readers to Titans, so the contrast needs one explicit line. The safest related-work framing, which the paper should write before a reviewer does: a kNN-LM-style non-parametric memory whose keys are whole-network binary routes and whose values are output-layer gradients, i.e. one-step memory-based parameter adaptation held in dual form with a substituted kernel.

For a patent, the base idea of storing hidden states, looking up neighbours and changing next-token scores has been public since 2017 to 2019, and the stored-error value is disclosed mathematically in the 2022 to 2023 papers above, so independent claims would have to rest on the route key and the carried kernel, with the stored-error nudge as a dependent element of the combination. That is a technical reading of the prior art, not legal advice, and no patent database was actually queried.

## Reviewers will ask for baselines that isolate each part and for the standard tables

The ablations follow directly from the neighbours. kNN-LM on the same stored passes with its dense final-layer key isolates the route key; kNN-LM with route keys isolates the subtracted prediction and log-space addition; MbPA or last-layer SGD with hidden-state keys isolates the kernel; true sequential last-layer dynamic evaluation isolates "errors against the frozen model" versus "errors against the updated model"; RetoMaton and a no-carry variant isolate the carry; a single-layer or continuous-activation key isolates "all layers" and "binary". The plain in-context baseline (put the 60 sentences in the prompt) and Saka-style test-time SGD on the same Qwen3 belong beside them.

On benchmarks, the field's yardsticks are reliability, generalisation and locality on zsRE and CounterFact at 1 to 1,000+ sequential edits on 7 to 8B models. GRACE scores 0.93 / 0.08 / 1.00 at 1,000 edits on LLaMA-2-7B, WISE 0.77 / 0.72 / 1.00 ([WISE](https://arxiv.org/html/2405.14768v2)), and MEMOIR 0.94 / 0.85 / 1.00 on LLaMA-3-8B, holding 0.87 / 0.78 / 0.98 at 15,000 edits ([MEMOIR](https://arxiv.org/html/2506.07899v4)). **Route memory's 100% / 97% recall of told sentences is the reliability column only, the one an exact activation-keyed memory wins by construction; GRACE's generalisation of 0.02 to 0.37 on paraphrases is the default expectation for such a memory until route memory shows otherwise.** Paraphrase generalisation, portability (MQuAKE, RippleEdits) and long-form evaluation, where short-form metrics fail to predict generative outcomes ([Rosati et al. 2024](https://aclanthology.org/2024.naacl-long.208/)), are all unreported. Locality will not be 1.00 by design, since nothing is gated and unrelated text drifts; "stays as likely under the frozen model" is closer to the perplexity surrogate proposed for detecting collapse ([Yang et al. 2024](https://aclanthology.org/2024.findings-acl.322)) than to benchmark locality, and both should be reported. INLAY cuts both ways on the missing gate: an oracle router ties a static policy on current counterfactual benchmarks because they contain no negative cases, but headroom appears once withheld-edit negatives are added ([Singh 2026](https://arxiv.org/abs/2608.26292)).

Scale is the other demand. Published tables use 1,000 to 15,000 edits on 7 to 8B models; the current result is 60 sentences on 0.6B parameters. Because every stored place pushes with no normalisation, the specific risk is additive interference as the store grows, so the curve to show is locality and fluency against the number of told items (60, 1,000, 10,000), plus the storage and compute cost of comparing 86,016 bits against every stored token at every step, and replication on a second model family given that Balogh's binary-routing structure weakened beyond GPT-2 Small ([Balogh 2026](https://arxiv.org/html/2603.10985v1)).

No statement about patents on activation-pattern keys, stored prediction error applied at inference, fast-weight or dual-form memories, or kNN-style LM augmentation from the large labs can be made. A real clearance needs direct database queries with class and assignee filters.

Several of the closest items were read at abstract or search-summary level only: INLAY (arXiv 2608.26292), whose key source is unstated in the abstract and which is the single paper most worth reading in full; the activation-steering memory (arXiv 2610.14958); Prometheus Mind (arXiv 2601.15324); S3-Attention ([arXiv 2601.17702](https://arxiv.org/html/2601.17702v2)), which uses trained sparse-autoencoder features as a retrieval index; SKIM ([arXiv 2610.36948](https://arxiv.org/abs/2610.36948)); ResMem ([arXiv 2611.00450](https://arxiv.org/html/2611.00450)); kNN-MT, kNN-Prompt and kNN-Adapter; Hardt & Sun; Dai et al. and von Oswald et al. on in-context learning as gradient descent. The researchers' accounts of ROME, MEMIT, MEND, MELO, IKE, MemoryLLM, Cartridges, Generative Adapter and the steering family come from recall of the papers, not a re-read, and are used here only as background.

Some of the most exact ancestors of "store the error, apply by kernel, never write weights" were never opened and are named here as leads without citation: the kernel adaptive filtering line (Kernel LMS, NORMA), Aizerman et al. 1964, Bottou & Vapnik's local learning, Ba et al.'s fast weights, and the arc-cosine and NTK gate-term results. The string-kernel and embedding-inversion literatures were not searched. Not checked at all: OpenReview full text for 2026 submissions, papers citing Balogh 2026, Cheng 2018 or the Neural Path Kernel (the likeliest place for a late collision), a direct arXiv listing sweep for November 2026, GitHub and Hugging Face native search, non-English venues, and kNN datastore variants that binarise hidden states or prune entries by model correctness. Every "not found" above is absence in roughly 100 queries, which is evidence and not proof.

## Conclusion

The search changes what the contribution is. Route memory is not a new learning principle; it is a new address and a new kernel wrapped around a correction rule that four papers between 2018 and 2023 each wrote most of. That is a stronger position than it sounds, because the two parts nobody has published are also the two parts that can be tested cleanly against named baselines: if all-layer binary routes beat kNN-LM's dense final-layer key on the same stored passes, and the carry beats RetoMaton and a no-carry variant, the paper has a result regardless of how the nudge is framed. If they do not, the method reduces to dual-form one-step MbPA and the novelty claim goes with it.

The work to do before any claim is filed or submitted is small and specific: read INLAY and arXiv 2610.14958 in full, check who cites Balogh 2026, run a real patent database search, and move the evaluation from recall of told text to paraphrase generalisation, store-size scaling and a second model. Positioning it as test-time learning for a frozen LM with a non-parametric store, rather than as model editing, matches the design and avoids being judged on a locality of 1.00 that an ungated method gives up on purpose.
